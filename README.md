# Practica-6---Creaci-n-de-un-Personaje-estilo-Crossy-Road-en-Blender
Proyecto realizado en Blender inspirado en el estilo voxel art de Crossy Road. Creé un alienígena llamado Glupix usando cubos y rectángulos, con colores llamativos y detalles como antenas, garras y espinas. Incluye un pequeño diorama y está organizado para facilitar futuras animaciones o exportación a videojuegos.
